# SO-101で実演から学び、黄色い物体を赤い入れ物へ運ぶ

SO-101を人が操作した実演からACT（Action Chunking with Transformers）を学習し、学習済みモデルでフォロワーを動かすためのコードです。ACTは作業カメラの画像と6関節の状態を入力に、次の一連の動作を予測します。

本プロジェクトでは実演20件を収集し、10,000ステップのモデルで、黄色い物体をつかんで赤い入れ物へ置く動作を実機で確認しました。以下の「5回×4組」は、同じ条件で成功率を測るために用意した評価手順です。20試行の結果は今後記録します。

## 4つのファイルの役割

| ファイル | 役割 |
|---|---|
| [train_act.py](./train_act.py) | 保存済みの実演データを読み込み、LeRobotの `lerobot-train` を起動します。学習・検証に使う実演の割合、学習ステップ数、モデルの保存間隔を指定し、学習結果をチェックポイントとして保存します。 |
| [evaluate_act.py](./evaluate_act.py) | 学習済みモデルを使う実機評価の進行役です。1組5回の試行を管理し、各回の動画・関節状態・動作指令を保存します。成功・失敗・中断は操作者が入力し、試行番号とともにCSVに記録します。 |
| [rollout_current_start.py](./rollout_current_start.py) | 1試行ごとに評価スクリプトから起動されます。カメラをLeRobotに登録し、フォロワーの6関節の現在位置を読み取ります。その値をモーターの最初の目標位置に設定してから、通常の初期化とACTによる制御へ進みます。開始姿勢は操作者が事前にそろえます。 |
| [so101_shared_camera.py](./so101_shared_camera.py) | Windows側の配信プログラムが更新する `latest.jpg` をWSL2／Ubuntuから読み取り、RGB画像としてLeRobotに渡します。接続時に画像が更新されたことを確認し、評価中は直近の画像を返します。 |

## 実演データで学習する

動作環境はWSL2／Ubuntu、LeRobot 0.6.1、CUDA対応のPyTorchです。LeRobotの学習用依存関係を導入した仮想環境で、これらのPythonファイルを置いたディレクトリから実行します。`--dataset` には `meta/info.json` を含むデータセットのルートを指定します。

```bash
python train_act.py \
  --dataset "$HOME/.cache/huggingface/lerobot/local/so101_yellow_pick_place_20_trimmed_v1" \
  --output runs/act_pick_place
```

今回のデータは20実演、合計15,540フレームです。実演単位で16件を学習、4件を検証に使用します。学習はFP32、バッチサイズ2で10,000ステップ行い、2,000ステップごとに検証損失を計算し、5,000ステップごとにモデルを保存します。今回の検証損失は8,000ステップで最小でした。保存されたチェックポイントは5,000と10,000ステップで、実機には後者を使用しました。

## 学習済みモデルを実機で評価する

Windows側で作業カメラのJPEG配信を起動し、キャリブレーション済みのフォロワーをWSL2に接続します。以下の `PORT` と `JPEG` は使用環境に合わせて置き換えてください。`--model` には重み・設定・前処理と後処理のファイルがそろった `pretrained_model` ディレクトリを指定します。

```bash
PORT="/dev/serial/by-id/フォロワーのUSB識別子"
JPEG="/mnt/c/Users/Windowsユーザー名/so101-camera-share/latest.jpg"

python evaluate_act.py --batch 1 \
  --model runs/act_pick_place/checkpoints/010000/pretrained_model \
  --port "$PORT" --jpeg "$JPEG" --output evaluation
```

1. 開始姿勢、ワーク、赤い入れ物の配置をそろえます。手を可動範囲から離し、Enterで1試行を開始します。
2. ACTが画像と関節状態から100ステップ分の動作を予測し、100ステップ実行してから再予測します。制御の目標は30 Hz、制限時間は1回60秒です。
3. 試行後に結果を入力します。終了時は自動帰還せず、保持トルクが残る設定です。姿勢を戻すときは、保持中のアームを手で無理に動かさないでください。
4. 5回でコマンドが終了します。次の組は同じコマンドの `--batch` を `2`、`3`、`4` と変えて実行します。それぞれ通算6～10回目、11～15回目、16～20回目に対応します。

結果は `evaluation/batch番号_日時/` に保存されます。`results.csv` には組番号、試行番号、データセット名、終了コード、操作者の判定が入ります。各試行のデータセットには `videos/`（作業動画）、`data/`（関節状態・動作指令）、`meta/`（記録形式・件数）が含まれます。
